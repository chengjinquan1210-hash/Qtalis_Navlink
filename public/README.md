## Answering guidance

- Separate general GNSS principles from receiver-, model-, hardware-, and firmware-specific behavior.
- Do not infer command syntax or product support from a similar product.
- Ask for model, firmware, interface, raw logs, and test conditions when they affect the answer.
- State uncertainty explicitly and link to the applicable primary reference.
- Never include customer-identifying information in examples.
